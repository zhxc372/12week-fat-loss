# 皮质醇管理与有氧优化指南

## 核心原则

> 用中低强度有氧提高总消耗，用力量训练保肌肉，用睡眠和碳水防止压力系统爆表。

现在最怕的不是"练得不够狠"，而是：**吃太少 + 睡太差 + 有氧太猛 + 药物脱水风险叠加**，然后皮质醇、饥饿感、心率、焦虑一起拉满。

---

## 1. 有氧三层结构

| 层级 | 内容 | 每周频率 | 目的 |
| ------- | ----------------------- | ---: | ----------------- |
| **基础层** | Zone 2 有氧：自行车、游泳、椭圆机、快走 | 5–6天 | 提高消耗、降焦虑、改善胰岛素敏感性 |
| **消耗层** | 长有氧：75–100分钟低强度 | 1–2天 | 拉大热量缺口 |
| **刺激层** | 轻间歇：30秒快 + 90秒慢 | 最多1天 | 提高心肺，不让身体太适应 |

每周有氧目标：**300–500分钟**，优先低冲击项目。

---

## 2. 什么是"皮质醇拉满"

身体长期收到"我快死了"的信号，来自五件事：
1. **热量缺口太大**
2. **碳水太低**
3. **睡眠太差**
4. **高强度训练太频繁**
5. **脱水、电解质紊乱、胃肠反应**

**减脂要制造压力，但不能制造"系统性危机"。**

## 3. 强度标准

| 强度 | 感觉 | 是否适合 |
| ---------- | --------- | -------- |
| Zone 1 | 很轻松，能完整聊天 | 恢复日用 |
| **Zone 2** | 微喘，能说短句 | **主力强度** |
| Zone 3 | 明显累，说话断续 | 少量使用 |
| Zone 4/5 | 很喘、顶不住 | 暂时少用 |

**主力是Zone 2，不是每天把自己练废。**

## 5. 训练调整规则

### 🟢 绿色状态：可以加有氧
- 睡眠 ≥ 6.5小时
- 静息心率没有明显升高
- 没有头晕、心慌、恶心、腹泻
- 腰腿没有加重
- 饮食蛋白和碳水吃够
→ 当天有氧加10–20分钟

### 🟡 黄色状态：只维持
- 睡眠 < 6小时
- 明显焦虑、烦躁
- 腿沉、腰酸
- 饥饿感很强
- 体重突然上涨但饮食没超
→ Zone 2有氧30–45分钟，不做间歇，力量减量30%

### 🔴 红色状态：降强度
- 呕吐、腹泻
- 明显脱水
- 心慌胸闷
- 腹痛
- 酮体阳性
- 站起来头晕
- 腰痛腿麻明显加重
→ 停训练，只轻走10–20分钟，补水、正常吃碳水，必要时联系医生

## 6. 防皮质醇拉满六条硬规则

### 规则1：每天碳水不能太低
- 每日碳水底线：100g
- 训练日：土豆熟重300–500g + 燕麦麸皮20–30g
- 训练前后必须有碳水
- **碳水不是敌人，失控才是敌人**

### 规则2：热量不要低于1500 kcal
- 长期低于1500 kcal → 睡眠更差、暴食风险上升、训练质量下降、焦虑加重、NEAT下降
- 不是要饿成尸体，是要变成能面试、能上班、能持续输出的人

### 规则3：高强度最多一周一次
- 轻间歇模板：热身10分钟 → 30秒快/90秒慢 × 6–8轮 → 放松10分钟（全程约30分钟）
- 一周最多一次

### 规则4：力量训练不能丢
- 每周至少：上肢推拉1–2次 + 下肢友好训练1次 + 核心稳定3次
- 有氧负责消耗，力量负责保肌肉和体型

### 规则5：睡眠是减脂药效放大器
- 优先评估睡眠呼吸暂停问题
- 下午3点后不喝咖啡
- 睡前2小时不做高强度训练
- 睡前30分钟不刷刺激内容
- 睡前热水澡/泡脚/拉伸10分钟
- 起床后晒光10分钟

### 规则6：不要用"多练"惩罚"吃多"
- 暴食后：热量回到1600–1700kcal，蛋白吃够120g，有氧60–75分钟Zone 2
- **不断食、不加倍训练、不脱水**
- 暴食后最错误的做法：断食 + HIIT + 自责

## 7. 每日模板

**早上**：起床称重 → 水300–500ml → 黑咖啡 → 晒光10分钟 → 轻走10分钟

**上午**：求职90分钟 → 第一餐（蛋白 + 土豆/燕麦麸皮 + 大量蔬菜）

**下午**：主训练（力量/有氧）→ 第二餐 → 肌酸3–5g

**晚上**：餐后走10–15分钟 → 不做高强度 → 睡前拉伸/呼吸10分钟 → 23:30前睡

## 8. 平衡公式

```
今天能不能加有氧？

睡眠 ≥ 6.5小时
+ 没有恶心腹泻
+ 没有明显心慌胸闷
+ 腰腿没加重
+ 昨天吃够蛋白和碳水
= 可以加10–20分钟Zone 2

只要有2项不满足
= 不加，只维持

只要出现呕吐、腹泻、酮体阳性、胸痛、严重气短
= 停训练，优先处理安全
```

| 项目 | 内容 |
| -- | -------------- |
| 热量 | 1600–1750 kcal |
| 蛋白 | 120–130g |
| 碳水 | 120–160g |
| 脂肪 | 40–50g |
| 有氧 | 60–90分钟 |
| 力量 | 每周3次 |
| 步行 | 每餐后10分钟 |
| 睡眠 | 尽量6.5–8小时 |

每周：3次健身房力量 + 3次自行车/椭圆机60分钟 + 1次游泳或长有氧90分钟 + 1天恢复走路 + 1次轻间歇（状态差就取消）

---

## 关键一句

> **有氧要加，但加在Zone 2，不加在天天玩命。热量要低，但不能低到身体报警。碳水要控，但不能控到生酮。训练要狠，但不能狠到影响睡眠和求职。**

每天真正的胜利标准：**吃够蛋白，保留碳水，完成有氧，完成求职，不崩盘。**
