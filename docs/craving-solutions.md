# 嘴馋急救与奖赏机制减肥手册

> **核心原则：嘴馋不是靠忍，是靠"换奖励"。**

大脑想要的是：**刺激、安慰、咸香、油脂感、成就感、逃避压力**。
你要做的是把"红烧肉/炸物/甜食"这个奖励，替换成**低热量奖励 + 行为奖励 + 成就奖励**。

---

## 一、嘴馋分级解决方案

### 0级：只是嘴巴寂寞
目标：给口腔刺激，不给热量
- 无糖可乐 / 气泡水
- 热茶 / 黑咖啡
- 黄瓜条 + 醋 + 生抽几滴
- 紫菜汤
- 海带木耳汤
- 刷牙 + 漱口水

### 1级：想吃咸香味
替代烧烤、红烧、卤味
- 红烧味鸡胸肉 80-120g
- 酱香豆腐 150-200g
- 卤蛋 1个
- 紫菜蛋花汤
- 木耳拌黄瓜
- 鸡胸肉蘸：生抽 + 醋 + 蒜 + 辣椒粉
- 核心：咸、辣、酸、热

### 2级：想吃肉（尤其红烧肉）
你想要的是"油脂感 + 肉感"，按优先级选：
1. 鸡腿肉去皮 100g
2. 瘦牛肉 80-120g
3. 红烧味鸡胸肉 100g
4. 红烧味豆腐 200g
5. 真红烧肉 1小块，20-30g，吃完立刻结束

**红烧肉可以尝，不可以开局。**

### 3级：想吃甜
- 无糖酸奶 200g
- 无糖酸奶 + 燕麦麸皮 10g
- 无糖可乐
- 代糖热可可（少量）
- 冷藏土豆 100g，撒盐和黑胡椒

⚠️ 替尔泊肽导致胃排空变慢时，晚上别加燕麦麸皮、菊粉等高纤维。

### 4级：焦虑型嘴馋
不是饿，是想逃避压力，**立刻执行**：
```
1. 离开食物现场
2. 喝温水200ml
3. 走路10分钟
4. 回来洗脸/刷牙
5. 如果还想吃，只吃蛋白质：鸡蛋1个 / 鸡胸肉80g / 豆腐150g
```

**焦虑型嘴馋，不用主食和油脂处理。**

### 5级：快失控了
执行**封顶方案**，目的是防止爆仓：
```
允许吃一份封顶食物：
- 鸡蛋2个
或
- 鸡胸肉120g
或
- 无糖酸奶250g
或
- 豆腐250g

吃完立刻刷牙，离开厨房。
不再追加第二轮。
```

## 二、嘴馋判断公式

问自己一句：**我现在愿不愿意吃鸡胸肉/鸡蛋/豆腐？**

| 回答 | 判断 | 处理 |
|-----|------|------|
| 愿意 | 真饿 | 吃蛋白质 |
| 不愿意，只想吃红烧肉/炸物/甜食 | 馋 | 用味觉替代 |
| 胃很撑但还想吃 | 奖赏系统在讨债 | 不加纤维，换热汤/咸香/刷牙/走路 |

## 三、奖赏机制减肥系统

### 1. 每日积分制（满分10分）
| 行为 | 分数 |
|-----|-----:|
| 吃够蛋白 | +2 |
| 碳水控制在100-160g | +1 |
| 没有高油高糖失控 | +2 |
| 有氧45分钟以上 | +2 |
| 力量/拉伸/康复训练 | +1 |
| 求职90分钟 | +2 |

### 2. 奖励规则
奖励**行为**，不奖励体重（体重受太多因素影响）。

| 得分 | 奖励 |
|-----|------|
| 6分 | 当天合格 |
| 8分 | 看一集剧/打一局游戏/洗热水澡放松 |
| 10分 | 存10-20元"变帅基金" |
| 连续7天≥8分 | 买一件小东西：衣服、训练手套、护腰、理发、简历服务 |

### 3. 非食物奖励库
| 想要的感觉 | 替代奖励 |
|-----------|---------|
| 爽 | 热水澡、按摩、泡脚、游戏20分钟 |
| 被安慰 | 热汤、热茶、听歌、躺下闭眼10分钟 |
| 成就感 | 打卡、体重趋势图、投递记录 |
| 体面感 | 理发、买衣服、护肤、整理桌面 |
| 掌控感 | 明日餐提前备好、训练完成截图 |
| 社交感 | 给朋友发今日完成记录 |
| 新鲜感 | 换一种低卡调味、换训练项目 |

### 4. 可控食物奖励
完全禁止会反弹，设计封顶奖励：

| 食物 | 封顶量 |
|-----|-------:|
| 红烧肉 | 1小块，20-30g |
| 锅包肉 | 1-2块 |
| 烧烤肉串 | 1-2串瘦肉 |
| 卤味 | 鸡蛋/鸡胸/牛肉优先 |
| 米饭 | 半碗以内 |
| 土豆 | 熟重100-200g |

**规则**：先吃蛋白和蔬菜 → 再吃封顶奖励 → 吃完立刻离桌 → 不追加第二轮

## 五、核心一句话

> **不要和嘴馋硬拼，要给大脑一个更便宜的奖励。**

你要训练的是这个回路：
```
嘴馋来了
→ 我有替代方案
→ 我没有爆仓
→ 我打卡得分
→ 我获得奖励
→ 我更相信自己
```

减肥真正成功的时刻，不是你完全不馋。
是你很馋，但你能把它导流到**低热量、高控制感、有成就感**的出口。
