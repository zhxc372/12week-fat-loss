# 皮质醇管理与安全速查

## 训练状态判断

### 🟢 绿色：可加有氧
- 睡眠≥6.5h + 无头晕心慌恶心腹泻 + 腰腿未加重 + 饮食吃够
→ 加10-20min Zone2

### 🟡 黄色：只维持
- 睡眠<6h / 焦虑烦躁 / 腿沉腰酸 / 饥饿强 / 体重突涨
→ Zone2 30-45min，不做间歇，力量减30%

### 🔴 红色：停训练
- 呕吐腹泻 / 脱水 / 心慌胸闷 / 腹痛 / 酮体阳性 / 头晕 / 腰腿加重
→ 停训练，轻走10-20min，补碳水补水，必要时就医

## 六条硬规则

1. **碳水≥100g/天** — 恩格列净+生酮=酮症风险
2. **热量≥1500kcal** — 低于会崩：暴食↑ 睡眠↓ 焦虑↑ NEAT↓
3. **高强度≤1次/周** — 不天天HIIT
4. **力量不能丢** — 上肢1-2次 + 下肢1次 + 核心3次/周
5. **睡眠优先** — 下午3点后不咖啡，睡前2h不高强度，评估睡眠呼吸暂停
6. **暴食后不断食** — 回到1600-1700kcal，蛋白120g，有氧60-75min Zone2

## 安全红线

**立即就医**：持续腹痛、反复呕吐腹泻、明显脱水、酮体阳性、胸痛、晕厥、严重气短、异常心慌、无法进食、发热感染、血糖异常伴随不适

**药物边界**：
- 替尔泊肽：不加量，胃肠严重时补液+联系医生
- 恩格列净：不生酮、不断食、不脱水，生病时警惕酮症

## 平衡公式

```
睡眠≥6.5h + 无恶心腹泻 + 无心慌胸闷 + 腰腿OK + 昨天吃够
= 可加10-20min Zone2

任意2项不满足 = 只维持
出现红色信号 = 停训练，保安全
```

## 暴食后修正
❌ 断食 + HIIT + 自责
✅ 热量1600-1700 + 蛋白120g + 有氧60-75min Zone2

## 纠偏规则
- 体重日涨 → 看七日平均，可能是水分/盐分/训练炎症
- 连续14天不降 → 每天减100kcal或每周加60min低强度有氧
- 暴食 → 回正常计划，不断食
- 没训练 → 最低补救：饭后走10min×2 + 居家核心10min
- 晚上特馋 → 喝水300ml + 出门走10min → 防崩补口
