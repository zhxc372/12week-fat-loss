# 12周减脂核心规则速查

## 每日营养目标

| 项目 | 目标 | 说明 |
|------|------|------|
| 热量 | 1600-1800 kcal | 训练多取高位，休息日取低位 |
| 蛋白质 | 110-130g | 鸡胸肉/鱼虾/鸡蛋/豆腐/酸奶 |
| 碳水 | 100-160g | 土豆/燕麦麸皮/红薯/玉米/少量米饭，**长期不低于100g** |
| 脂肪 | 40-55g | 鸡蛋/鱼肉/少量烹调油 |
| 有氧 | 45-90分钟 | 自行车/游泳/椭圆机/快走优先 |
| 力量 | 每周2-3次 | 保肌肉保代谢 |
| 求职 | 90-120分钟 | 每天 |

## 食材库

### 主蛋白（每天必须吃够）
- 鸡胸肉：熟重180-250g，可一次做3天量
- 鱼/虾：200-300g
- 鸡蛋：1-2个
- 豆腐：300-500g
- 无糖酸奶：200-300g

### 主碳水
- 土豆：熟重300-500g/天
- 燕麦麸皮：20-40g
- 红薯：熟重150-300g
- 玉米：1根以内
- 米饭：熟饭半碗（训练日或外食）

### 高体积蔬菜（不限量）
- 海藻类：海带/裙带菜/紫菜，每周2-3次
- 菌菇类：木耳/香菇/金针菇/平菇/杏鲍菇
- 叶菜类：生菜/油麦菜/菠菜/小白菜/娃娃菜，400-800g
- 瓜茄类：黄瓜/西红柿/冬瓜/丝瓜
- 根茎少量：胡萝卜/白萝卜

### 调味
- ✅ 黑胡椒、辣椒粉、蒜、醋、生抽少量、芥末、孜然、咖喱粉少量、番茄、柠檬汁、无糖代糖少量
- ❌ 沙拉酱、花生酱、芝麻酱、老干妈、糖醋汁、火锅蘸料、奶茶、酒

## 四套菜单轮换

### A：鸡胸肉土豆海带日
- 第一餐：鸡胸肉220g + 土豆250g + 海带木耳汤 + 黄瓜/生菜300g + 燕麦麸皮25g
- 第二餐：鸡胸肉200g + 胡萝卜100g + 菌菇400g + 豆腐300g
- 防崩：无糖酸奶200g / 鸡蛋2个 / 鸡胸肉100g

### B：鱼虾豆腐日
- 第一餐：虾仁250g或鱼肉300g + 土豆200g + 木耳黄瓜凉拌 + 燕麦麸皮20g
- 第二餐：豆腐400-500g + 鸡蛋1个 + 绿叶菜500g + 紫菜汤
- 防崩：鸡胸肉100g / 无糖酸奶200g

### C：健身房训练日
- 训练前60-90min：土豆150g + 黑咖啡
- 训练后：鸡胸肉250g + 土豆250g + 蔬菜500g + 肌酸3-5g
- 第二餐：鱼/虾/瘦牛肉200-300g + 菌菇木耳 + 豆腐200g
- 防崩：无糖酸奶200g

### D：没胃口日
- 无糖酸奶300g、鸡蛋2个、豆腐400g、鸡胸肉100-150g、土豆泥200g、紫菜蛋花汤、燕麦麸皮20g
- 目标：蛋白和碳水不归零

## 外食规则
1. 先吃蛋白：鸡/鱼/虾/牛肉/瘦肉/豆腐
2. 再吃蔬菜
3. 油炸/糖醋菜最多2块
4. 主食最多半碗，不喝含糖饮料，不喝酒
5. 汤少喝，重油菜少沾汁
6. 吃完走10-15分钟

## 晚间防崩
- 想吃甜 → 无糖酸奶/无糖饮料/热茶/黑咖啡
- 想咀嚼 → 黄瓜/西红柿/胡萝卜条/木耳凉拌
- 想吃肉 → 鸡胸肉100g / 鸡蛋1-2个 / 虾仁100g
- 想吃主食 → 土豆100-150g蒸煮
- 想报复性进食 → 喝水300ml + 出门走10分钟 → 防崩补口
- **防崩三选一：无糖酸奶200g / 鸡蛋2个 / 鸡胸肉或虾仁100g，20:30前完成**

## 每周采购
- 鸡胸肉2.5-3.5kg、鸡蛋14个、豆腐4-6盒、鱼/虾1.5-2kg、无糖酸奶7杯
- 黄瓜7-10根、绿叶菜7份、木耳1袋、海带/裙带菜1袋、菌菇1.5-2kg、西红柿7个
- 土豆4-6kg、红薯/玉米少量、燕麦麸皮、菊粉、咖啡、肌酸
