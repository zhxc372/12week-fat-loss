# 12周减脂打卡工作流

## 当收到张小厨的晨间问卷回复时

### Step 1: 解析数据
从回复中提取17个字段：体重、7日平均、腰围、睡眠质量、排便、夜间进食、整体状态、焦虑、蛋白范围控制、暴食、训练、最大问题、改进策略、健身房、游泳、外食、求职任务。

### Step 2: 保存数据
将原始数据写入 `/root/.openclaw/workspace/projects/12week-fat-loss/data/daily/YYYY-MM-DD.md`（使用当天日期），格式参考 `data/daily/template.md`。

### Step 3: 生成当日方案
读取以下参考文档：
- `projects/12week-fat-loss/docs/plan-full.txt` — 12周执行手册（菜单、训练计划、外食规则）
- `projects/12week-fat-loss/docs/cortisol-and-cardio-guide.md` — 皮质醇管理指南（训练强度判断）
- `projects/12week-fat-loss/data/profile/base.md` — 基础信息
- `projects/12week-fat-loss/data/daily/` — 历史数据（最近7天，用于计算趋势）

生成方案后追加到当天的数据文件中。

### Step 4: 输出方案
直接回复，格式：

**📋 今日风险判断**
{绿色/黄色/红色 + 原因}

**🍽️ 今日饮食方案**
{热量/蛋白/碳水/脂肪目标}
{具体菜单，使用已有食材}

**💪 今日训练方案**
{有氧内容+时长}
{力量训练内容}
{禁止动作}

**💼 今日求职任务**
{具体90-120分钟任务}

**⚠️ 纠偏建议**
{根据昨日问题给调整}

**📌 明日提醒**
{明天准备什么}

## 每周复盘

每周日晚（或周一早上收到数据后），如果当前是周日，自动触发周复盘：
1. 读取本周 `data/daily/` 中所有数据
2. 按 `checkin-templates/每周复盘.md` 模板生成复盘
3. 保存到 `data/weekly/W{N}.md`
4. 推送到GitHub

## 数据提交

每次保存新数据后，执行：
```bash
cd /root/.openclaw/workspace/projects/12week-fat-loss && git add -A && git commit -m "data: YYYY-MM-DD daily checkin" && git push
```

## 安全红线

- 出现呕吐/腹泻/酮体阳性/胸痛/晕厥/严重气短 → 红色状态，建议立即就医
- 热量不低于1500kcal
- 每日碳水≥100g
- 不建议自行调整处方药
- 暴食后不断食，用轻量修正
